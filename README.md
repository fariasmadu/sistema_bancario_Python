# Projeto Sistema Bancário em linguagem Python
Criação de software de um sistema bancário em linguagem Python, utilizando paradigma de programação orientada a objeto (POO) para representar dados e métodos, deixando assim o programa mais robusto e seguro, criando usuário, conta, realiza depósito, saque, lista usuários e contas cadastradas.

# Tecnologias Empregadas
Python

# Funcionalidades
- Depositar
- Sacar
- Ver Extrato
- Criar Nova Conta
- Lista Contas Criadas
- Cria Novo Usuário
